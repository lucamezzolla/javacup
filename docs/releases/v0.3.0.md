# Javacup v0.3.0 MVP

Javacup v0.3.0 is the first Local JVM Memory Diagnostic MVP release.

This release closes the initial local MVP scope: local dashboard, Java process discovery, external JVM probing through local JDK tools, structured diagnostics, sample collection, readable report previews, JSON report archive and archived report comparison.

## Highlights

- Local Vaadin dashboard.
- Local Java process discovery.
- External JVM metrics through local JDK diagnostic commands.
- Structured heap and VM uptime information.
- Probe status and probe failure diagnostics.
- Heap, Metaspace and sample-quality diagnostics.
- Session health summary in External Metrics.
- Readable report preview with:
  - Report verdict
  - Probe summary
  - Trend interpretation
  - Diagnostic summary
  - Recommended next actions
- JSON report download/archive.
- Archived report search, preview and comparison.
- MVP verification script: `scripts/verify-mvp.sh`.

## Verification

The MVP release was verified with:

```bash
./scripts/verify-mvp.sh
```

Expected result:

```text
Javacup MVP verification completed successfully.
```

## Scope note

This is the first local MVP release, not a 1.0 release.

Future work should be treated as post-MVP improvement work, such as packaging, richer charts, additional diagnostics, JFR analysis, improved exports and long-term persistence.
